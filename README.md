# 📊 Call Center Dashboard (Excel)

## 📌 Overview
This project presents an interactive Call Center Dashboard built in Microsoft Excel to analyze call performance, revenue, customer satisfaction, and representative efficiency. The dashboard provides clear insights using dynamic charts, KPIs, and filters.

---

## 📁 Dataset
- Source: Excel file  
- Includes:
  - Call records (daily/monthly)
  - Revenue/amount data  
  - Customer details  
  - Representative performance  
  - City-wise data (Cincinnati, Cleveland, Columbus)  

---

## 🛠️ Tools & Features Used
- Microsoft Excel  
- Pivot Tables  
- Pivot Charts  
- Slicers (Representative filter)  
- Conditional Formatting  
- KPI Cards Design  

---

## ⚙️ Project Workflow
1. Data Cleaning  
   - Structured raw data  
   - Removed inconsistencies  

2. Data Analysis  
   - Created pivot tables  
   - Calculated KPIs (Calls, Revenue, Duration, Ratings)  

3. Dashboard Creation  
   - Designed interactive visuals  
   - Added slicers for dynamic filtering  
   - Built KPI cards for quick insights  

---

## 📈 Dashboard Features

- 📞 Total Calls: 1,000  
- 💰 Total Revenue: $96,623  
- ⏱️ Total Call Duration: 89,850  
- ⭐ Average Rating: 3.9  
- 😊 Happy Customers: 307  

### Visual Insights:
- Call Trend (Monthly analysis)  
- Day-wise call distribution  
- Female vs Male callers comparison  
- Representative-wise performance (Calls & Revenue)  
- City-wise revenue breakdown  
- Interactive slicer for representative filtering
